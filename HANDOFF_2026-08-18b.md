## Bugs this session found and fixed (all in earlier components)

Each is in audit M with the reasoning; the short version:

- **`ownership.duckdb:blocks.geometry_wkt` is EPSG:3978, not lon/lat** (M1).
  Every existing consumer joins on `block_id`, so no one had intersected it. The
  first spatial query returned 0 blocks for ground holding 698. Anything else
  reaching for that column must transform it — the store carries no CRS metadata.
- **A parquet cache keyed on (path, mtime) but not the column projection** (M2).
  Only failed in the live server, where `/api/catalog` always warms the cache
  before `events_layer` reads it. Every direct call passed.
- **The event scrubber spanned 1899→2027** (M3) — Yukon's paper record — while
  the layer it drives draws Ontario from 2018-04. Now jurisdiction-scoped and
  clipped to today.
- **`update_all.py` ran a national harvest when imported** (M4). No `__main__`
  guard, so an ordinary import check launched `harvest.py` against live
  endpoints. Now guarded, and a static check confirms no module in `src/` does
  work at import.
- **MLAS date columns need `pytz`** through DuckDB's Python conversion. Cast to
  VARCHAR in SQL rather than adding a dependency.

## No outbound requests, deliberately (audit M5)

The old inline UI pulled MapLibre from unpkg and tiles from
`basemaps.cartocdn.com`. A tile fetch is one request per tile per pan, each
carrying the viewport — which is *where we have decided to look*, the compact
form of the joined signal Master §8 calls the defensible edge. MapLibre is now
vendored (`viewer/vendor/`, BSD-3, hashes in `NOTICE.md`), the map's ground is
the provincial boundary and lakes from `geo.gpkg`, and the style declares no
`glyphs` or `sprite` origin. Dossier figures are inlined as `data:` URIs, so a
rendered dossier opens with no server and no network.
`test_mapapi.py::test_viewer_makes_no_external_request` asserts this over the
viewer sources and `serve.py`, rather than trusting it.

## Known broken / deliberately unfinished

Everything in the previous handoff still stands (QC geochem OOM, `SK_SMDI` 140
rows, `ON_GEOPHYS` raw only, transfer fee absent), minus Nunavut, plus:

- **No vector tiles.** Deliberate (audit M6): H3 parent aggregation covers every
  zoom at interactive rates today. MVT becomes worth building when a layer
  without an H3 id — claims at province zoom — needs to be drawn, which the
  viewer currently avoids by bbox-filtering instead.
- **The r9 fabric is Abitibi only.** Land state, and therefore the land layer and
  the dossier inset, exist only where `open_ground.py` has been run. Other AOIs
  need `python src/land/open_ground.py --aoi <id>` first.
- **`_feature_percentiles` recomputes percentiles per request** over the ~1 M-row
  long-format feature frame. Fast enough cached (~0.1 s) but it is a full scan
  per feature; if the feature store grows, precompute ranks.
- **One AOI, one model, one jurisdiction** in the catalog. Everything is keyed to
  generalise, but nothing else has been built to test it against.
