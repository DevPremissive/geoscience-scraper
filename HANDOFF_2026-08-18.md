## Traps that cost time in this session

- **A snapshot directory is a DELTA, not a complete copy.** `harvest.py` only
  writes changed files. Use `process.resolve_snapshot()`, never `latest()`.
  Reading the newest directory alone is how every Ontario tenure count came from
  46% of the province for two months.
- **Ontario staking events need BOTH MLAS registers.** The cancellation register
  holds only claims that ENDED; using it alone reported ~2,000 claims staked in
  2025 against an actual 89,466.
- **`HOLDER` has two formats.** Operational: `(100) NAME` where the number is a
  PERCENTAGE. Cancelled: `(408864) NAME (100%)` where the leading number is a
  CLIENT ID. And split on `,\s*(?=\(\d)`, never on any comma, or every company
  named ", INC." is lost.
- **The embedding limit is TOKENS (~512), not characters.** 2,000 chars embed,
  2,600 fail with lithology text. Chunk conservatively and back off on refusal.
- **Criticality is scored on OPEN cells.** Anything asking "is this claim on
  critical ground" must check neighbours, or it silently matches nothing.
- **Three corpus premises in the plans are false** — CGMC legend (a QGIS style
  file), MRDS (87% US, 1,551 Canadian records), and Zn-Pb MVT as the Ontario
  starter system (765 zinc+lead occurrences, and Ontario is not an MVT
  province). See audit K.
